# Fur Missile 

  

Fur Missile is a full-stack K9 training and mission-management application. 

  

## Features 

- Handler registration/login 

- JWT access authentication with HttpOnly refresh cookie 

- Working Dog CRUD 

- Training Mission CRUD 

- Mission-location weather 

- Protected AI mission-badge generator 

- Responsive React interface 

- Django and Cypress tests 

  

## Stack 

- React + Vite 

- React Router DOM 

- Axios 

- Django REST Framework 

- SimpleJWT 

- PostgreSQL / Psycopg3 

- OpenAI API 

- Docker Compose 

- Gunicorn 

- Nginx 

- GitHub Actions 

- AWS EC2
